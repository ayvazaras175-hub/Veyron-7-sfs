VEYRON-7 | PNG TEXTURE PACK (DRAFT)
===================================

Contains 8 equirectangular 2048x1024 PNG surface maps:
V7_Krix.png   - rocky world
V7_Velora.png - lava world
V7_Nymos.png  - ocean world
V7_Dravon.png - gas giant bands
V7_Eryx.png   - icy giant bands
V7_Polarys.png- icy outer world
V7_Luma.png   - rocky moon
V7_Orbis.png  - rocky moon

IMPORTANT:
These are original procedural texture prototypes. They are not yet connected
to the planet .txt references in the GitHub repository and have not been
tested inside SFS. The planet data must reference these exact base names
(without .png) before the game can use them. The star Veyron currently uses
an atmosphere gradient reference rather than a surface texture in its data.
